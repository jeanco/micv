# cv-portafolio

- Diseño limpio y profesional
- Totalmente adaptable a móviles
- Fácil de editar (solo texto)
- Enlace directo a WhatsApp
- Preview en tiempo real

## 🚀 Cómo usarlo

1. Entra a: [cv-portafolio](https://devmaster19.github.io/cv-portafolio/)
2. Busca tu perfil en Google
3. Copia y pega tus datos en los campos vacíos
4. ¡Listo!

> **💡 Consejo:** Para obtener mejores resultados, ten tus enlaces listos antes de empezar.

## 🔧 Configuración local

Si quieres editarlo en tu computadora:

1. Clona el repositorio
2. Abre el archivo `index.html`
3. Edita el texto donde dice "Escribe aquí..."
4. Recarga la página para ver los cambios

## 🎨 Personalización

- **Colores:** Busca donde dice `color-primary` en el archivo `style.css`
- **Tipografía:** Cambia las fuentes en la sección de estilos
